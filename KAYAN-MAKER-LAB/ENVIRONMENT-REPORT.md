## 3. الناقص

- **برامج مونتاج مع واجهة** (Premiere، DaVinci Resolve، CapCut): ما في، وما بتشتغل بهيدي البيئة. المونتاج بيصير بالكود.
- **Remotion و Blender و SoX:** مش منزّلين، ومش لازمين لهلّق.
- **أوزان خط Plex الخفيفة** (Light و Regular): مش موجودين. بيتنزّلوا من npm إذا لزموا، بعد الموافقة.
- **خدمات الذكاء الاصطناعي** (Google Flow، Gemini، ElevenLabs): ما في وصول إلها من البيئة. الصور والمقاطع والصوت لازم تترفع من صاحب الحساب.

## 4. الخطوات الجاية المقترحة

1. **قرار اللون:** محرّك الفيديو ودليل الأسلوب الحاليين معتمدين `#1DE5F5`، والإعدادات الجديدة بتقول `#12DFEF`. لازم ينحسم مين المعتمد لينعمّم على كل شي.
2. **سير العمل لكل إعلان:**
   1. نسخ `AD-TEMPLATE` لمجلد باسم الإعلان.
   2. تعبئة البريف والسكربت والستوريبورد.
   3. كتابة برومتات Flow / Nano Banana.
   4. صاحب الحساب بيولّد الصور وبيحطها بـ `05-FLOW-ASSETS`، والصوت بـ `06-AUDIO`.
   5. التركيب والرندر.
   6. الفيديو النهائي بـ `08-EXPORTS`.
   7. الفحص النهائي بـ `09-REPORT`.
3. **إعلان «Imagine it. We make it real»:** تجهيز مجلدو وتعبئة البريف والسكربت والستوريبورد من الطلب المعتمد.
4. **مستوى الصوت:** ريلات السوشيال ميديا عادةً −14 LUFS، والفيديوهات لهلّق عم تطلع على −23.6 LUFS متل الفيديو المرجعي. لازم ينحسم.

## 5. العوائق التقنية

- **البيئة مؤقتة:** لازم كل شي ينحفظ بالمشروع ويترفع.
- **المستودع منشور عـ GitHub Pages:** أي شي جوّا المشروع بيصير بينفتح للعموم بعد الدمج بالفرع الرئيسي، والصور والفيديوهات بتكبّر المستودع. **الاقتراح:** `KAYAN-MAKER-LAB` بمستودع خاص منفصل، أو ما ينرفعوا الصور والفيديوهات الكبيرة.
- **ما في وصول للـ API تبع Flow و Gemini و ElevenLabs:** المواد بتوصل بس عن طريق الرفع.
