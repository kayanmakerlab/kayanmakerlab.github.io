# KAYAN MAKER LAB — video production workspace

- `BRAND/` — brand configuration (`brand.json`, `BRAND.md`)
- `PRODUCTION-TEMPLATES/` — master Markdown templates (brief, script, storyboard, asset list, Gemini review, final QC)
- `ADS/AD-TEMPLATE/` — copy this folder for each new ad (`cp -r ADS/AD-TEMPLATE ADS/2026-11-XX-name`)

Rendering uses the project skill `.claude/skills/kayan-video` (Chromium + FFmpeg).
Large media (Flow images/videos, renders) can be big; keep exports small or ask before committing.
